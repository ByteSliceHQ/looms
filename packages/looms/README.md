# @swirls/looms

Looms is an event-sourced runtime for durable agents and workflows.

```sh
bun add @swirls/looms
```

You don't need to write Effect code to use Looms. Looms is built on Effect, and Bun, npm, and pnpm install it for you; with Yarn, add `effect` (`^4.1.4`) yourself. If your app uses Effect too, Looms shares your copy.

Import the core runtime from `@swirls/looms`, or use explicit modules such as `@swirls/looms/agent` and `@swirls/looms/react`. See the [repository README](https://github.com/ByteSliceHQ/looms#readme) for the full guide.

Release notes are available in [`CHANGELOG.md`](./CHANGELOG.md).
